# Bluetooth Qualification Glossary (Draft)

## Source documents

- Qualification Program Reference Document (QPRD) v4
- Test Declaration Best Practices v16

This glossary defines terms as used within the Bluetooth Qualification Process. Definitions apply only where explicitly referenced by the QPRD.

---

## Core Qualification Identifiers

### QDID — Qualified Design ID

A unique identifier assigned to a **Design** that has successfully completed the Bluetooth Qualification Process.

A QDID may be used to reference an existing Design when qualifying a Product, creating a new Design, or combining Designs during qualification.

(Source: QPRD v4, Acronyms and usage throughout Sections 3 and 4)

---

### DN — Design Number

A reference number issued for each unique Design when a Product using that Design first completes the Bluetooth Qualification Process.

(Source: QPRD v4, Definitions Table 1.1)

---

### DID — Declaration ID

An identifier used in the qualification process to reference a Design in certain qualification scenarios.

(Source: QPRD v4, Acronyms)

---

## Qualification Process Concepts

### Design

An implementation of one or more Bluetooth Specifications.

A Product includes exactly one Design.

(Source: QPRD v4, Definitions Table 1.1)

---

### Product

A single item sold and marketed under a unique name or trademark by a Member, containing exactly one Design.

(Source: QPRD v4, Definitions Table 1.1)

---

### Qualified Product

A Product that has successfully completed the Bluetooth Qualification Process and is listed in the Qualified Product database.

(Source: QPRD v4, Definitions Table 1.1)

---

### Bluetooth Qualification Process

The defined process by which a Product demonstrates compliance with Bluetooth Specifications, including Design specification, testing, documentation submission, and verification.

(Source: QPRD v4, Section 3)

---

## Documentation & Evidence

### ICS — Implementation Conformance Statement

A document produced by the Bluetooth SIG for each Bluetooth Specification that identifies the features of that specification.

(Source: QPRD v4, Definitions Table 1.1)

---

### ICS Form

A form completed by a Member for each Design to identify all features of the Bluetooth Specifications implemented in that Design.

(Source: QPRD v4, Definitions Table 1.1)

---

### IXIT — Implementation eXtra Information for Testing

A form completed by a Member providing additional configuration details to facilitate testing beyond the ICS.

(Source: QPRD v4, Definitions Table 1.1)

---

### Test Declaration

A completed test plan uploaded during qualification, documenting test execution results, verdicts, test systems, and references to test reports.

(Source: QPRD v4 Section 3.2.2.5; Test Declaration Best Practices v16)

---

### Test Report

Documentation providing detailed results of executed test cases, required for mandatory tests during qualification.

(Source: QPRD v4 Appendix A; Test Declaration Best Practices v16)

---

## Test Governance

### TCRL — Test Case Reference List

A document identifying applicable test specifications, versions, and test cases used during qualification for a given Bluetooth Specification.

(Source: QPRD v4, Definitions Table 1.1)

---

### TCW — Test Coverage Waiver

A waiver granted by Bluetooth SIG allowing specific qualification requirements or test cases to be waived under defined conditions.

(Source: QPRD v4, Appendix B)

---

### TSE — Test Set Erratum

A report tracking errors in qualification requirements or test documents and the fixes applied to resolve them.

(Source: QPRD v4, Definitions Table 1.1)

---

## Test Facilities

### BQTF — Bluetooth Qualified Test Facility

An accredited test facility authorized to perform testing for any Member, with results accepted by Bluetooth SIG.

(Source: QPRD v4, Definitions Table 1.1)

---

### BRTF — Bluetooth Recognized Test Facility

An accredited test facility authorized to perform testing for itself, with results accepted by Bluetooth SIG.

(Source: QPRD v4, Definitions Table 1.1)

---

## Database & Publication

### Qualified Product Database

The official Bluetooth SIG database listing Qualified Products and associated Design identifiers (DNs, QDIDs), with controlled visibility rules.

(Source: QPRD v4, Section 4)

---

### Product Qualification Date

The date on which the Bluetooth SIG confirms that a Product has successfully completed the Bluetooth Qualification Process.

(Source: QPRD v4, Definitions Table 1.1)

---

### Product Publication Date

The date on which Qualified Product details become visible to the public and other Members in the Qualified Product database.

(Source: QPRD v4, Definitions Table 1.1)
