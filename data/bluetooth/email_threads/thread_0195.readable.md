アルインコ桐本様アリオンの酒井です。いつもお世話になっております。

Host Stack追記の見積依頼書をご送付いただきありがとうございます。

私の仮ProjectでD046352 (QDID:[ID])とD046353(QDID:[ID])をIncludeして

RFおよびRF PHYのICSを追記してConsisystency Checkを掛けた結果、RF PHYは

Class 1でD046352のLLにInvalidは出ませんが、RFではClass 1(RF 1/1:YES)では以下のInvalidが発生します。

If [RF] (1/1) is Supported then [LMP] (31/1) is Mandatory

従ってD046352 (QDID:[ID])をIncludeする場合にはRF:Class 2 (RF 1/1:NO)で、

RF PHY: Class 1 (RF PHY 1/15:YES)としないとInvalid=0にならず登録が最後まで進みません。見積依頼書にはrf:Class 1と記載されていますが、RFはClass 2での登録でよろしいでしょうか。

次にRF/RF PHYのICSを入力して提出いただくPTSレポートの比較照合を行いますのでワイヤレスT様からHFP ICSとBAS ICSを入手してください。さらにPTSレポートご提出いただく際に抜けのないよう事前に登録に必要なPTSレポートの試験項目をお知らせしますのでPTS試験実施された方(ワイヤレスT様?)に事前にご送付ください。

現時点でPTSのIOPT試験は以下の項目が必要と確定しております。

IOPT/SR/COD/[ID]

IOPT/BAS/SR/[ID]/[ID]

IOPT/HFP/HF/SDPR/[ID]

IOPT/HFP/HF/CGSIT/SFC/[ID]

IOPT/SPP/DEVA/CGSIT/SFC/[ID]

IOPT/SPP/DEVB/SDPR/[ID]

引き続きよろしく願いいたします。
