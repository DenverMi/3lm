< 回答 >

プロファイル試験は製品および PTS 実行ソフトの微妙なタイミングの違いにより同じ環境で同一

PTS バージョンであっても中々 Pass しないが、繰り返し試験すると Pass するという結果が出ることがあります。

そのため、何度も同じ環境で試験を繰り返して Pass が得られた、あるいは PTS バージョンを替えて

Pass が得られたという場合、他の Pass しなかった結果は捨てて Pass ログだけを認証エビデンスとすることが許容されます。「いずれかの結果で Pass していれば Pass として扱う」というご認識で間違いございません。

<回答>

PTS更新バージョンリリースは2つのケースがありまして、

(1)コア仕様リリースタイミングに合わせて新しいプロファイルを追加した末尾0のケース

(2)報告されたバグを修正した随時更新で、末尾が0以外のケース経験的にはどの更新でもリグレッションバグ(それまで正常に試験できた項目がPTSのバグでPassが得られなくなる）

が散見されますが、リリースタイミング優先で準備された(1)のケースが最もリグレッションバグが多く、

短い間隔で末尾 1 - 2 - 3 と更新リリースが行われます。

それぞれのバージョン毎に PTS Release Note が準備されており、最新の8.7.3は下記URLで確認できます。

ここで注目すべきはMPSが19項目バグフィックスされていて、御社のMPS試験でPassしない項目も対象となっています。

従ってMPSの再試験は8.7.3で実施を予定しております。

他のプロファイルに関してはPTSがおかしいと思われる場合およびPTS Release Noteでバグフィックスされた項目対象の試験を行う場合を除き、安定してPassするバージョンでの試験続行が安全です。

なお、最新リリースは2024/10/25の8.5.3ですが、8.5.4がリリースされたらPTS Release Noteの内容で使用適否を判断することになります。認証規定上は最新リリースでの試験結果を認証エビデンスとすること、

および異なるバージョンのレポートとの混在利用が可能です。
