[ID]（[ID] /QDID:[ID] /v5.3)はLL, [ID], BB, LMP, HCI階層を含む登録です。

登録の進め方は御社モジュールでRFおよびRF PHY試験を実施し、PassレポートをエビデンスとしてQCA6698AQのサポート階層へRFおよびRF PHYを追加した登録を行う手順となります。

ここでご注意いただきたいのはQCA6698AQは [LL]8/11 LE Class 1:YES で登録されています。

このためRF PHYは1/15がClass 1:YESでないと階層間不整合が生じて登録手続が完結しません。

言い換えれば御社のモジュールがLEモードで10mW以上100mW未満の送信出力でないとQCA6698AQ

を参照して組み合わせた登録ができず、もし御社が今回のモジュールがLEモードで10mW未満の送信出力をご希望であれば他のControllerスタックで[LL]8/11 Class 1:NOで登録されたものを選択するか、Q社に[LL]8/11 Class 1:NOでの更新登録を打診してください。

見積は下記の通りです。（AoA, AoD機能には非対応の登録です。）
