⇒ QDID:[ID] 単体登録では Host 階層のみですので QDID:[ID] と組み合わせた End
Product 相当の登録で初めて Host 階層と Controller 階層との階層間不整合チェックが実行されます。その結果、

[GAP] (4/7) Synchronization Establishment as receiver
:YES

[BB] (3a/2) Connectionless Peripheral Broadcast Receiver： NO

との不整合（[GAP] (4/7) は [BB]
(3a/2) がサポートされている場合の Option 機能、非サポートの場合は常にサポート NO）が生じます。

製品が Connectionless Peripheral Broadcast Receiver を必要としなければ影響ありませんが、

客先登録に上記不整合内容が踏襲されて残ります。
QDID:[ID]
If [RFPHY] is Supported and [RFPHY] (1/15) is Not Supported then [LL] (9/11) is Excluded

⇒ これは QDID:[ID] 自身の不整合 ( 登録時の [LL](9/11) 指定ミス ) で、モジュール仕様は非 Class
1

ですので [RFPHY](1/15):NO(Not Supported ) の方がモジュールの実態を反映しています。しかし製品内容にも [LL](9/11):YES というミスが継承されて残りますが、それ以外は実質 [LL]
(9/11):NO

です。
