[ID]: nRF Connect 2.8.0によるBLE 5.3のローレベル通信。

上記3つを参照することで、nRF52シリーズのSoC全て（nRF52805、nRF52832、nRF52840等）で、

nRF52シリーズをペリフェラルとして使用する場合でも、ホスト側（例えばデータ収集用の中継器）
として利用する場合でも追加の製品登録料金等不要で開発・販売可能。
ただし、機器の型番が変わる場合には、追加料金は不要だが製品の登録自体はする必要がある。

⇒nRF Connect SDK 2.8.0でペリフェラル機能のオブジェクトコードを実装したRF52シリーズのSoCを搭載した製品は、今回の登録のProduct Listへ派生モデルとして無料追加登録することで認証手続が完了します。

ただし、SoftDevice SDK X,X.XなどnRF Connect SDK 2.8.0以外で作成したオブジェクトコードを実装したRF52シリーズのSoCを搭載した製品は対象外です。
nRF52シリーズを組み込んでいる、サードパーティが開発したモジュールを使用した場合でも、
同様に追加の製品登録料金等不要で開発・販売可能。
下記BM832のデータシートを見るとQDID 97989と書かれているが、を参照することででモジュールに内臓されているnRF52832を参照しているので、BM832を組み込む場合でもQDID 97989を参照する必要はない。

⇒BM832はNordic社登録のQDID:97989(End Product)をそのまま参照したDeclaration登録で、BM832自身は

QDIDを取得していません。QDID:97989はNordicが下記Component登録を参照したDesign登録でSoftDevice

5.0.0 SDKから作成したFWを実装しているという登録内容となっています。

・94115 (RF PHY /Component)

・93865 (S132 nRF52 link layer / Component)

・94418 (S132 nRF52 5.0.0 Host Layer / Component)
